# Quickstart

A five-minute walkthrough that creates a devnet subscription and executes a payment end-to-end.

## Overview

This page will guide a new integrator from zero to a working pull-payment on
devnet. It is the fastest path to verify the Tributary SDK against the live
program and is the recommended entry point after reading the home page.
