# Discord Community Launch Guide

## Setup Steps

1. Create server: Go to Discord, click +, name "Tributary Community".
2. Channels:
   - #announcements (read-only for updates)
   - #general (open chat)
   - #dev-help (integration questions)
   - #integrations (showcase partnerships)
   - #ama (weekly office hours)
   - #memes (fun content)
3. Roles: Admin, Moderator, Ambassador (for early adopters).
4. Invite link: Generate permanent invite, share in posts.

## Initial Content

- Welcome message: "Welcome to Tributary! We're building automated subscriptions on Solana. Post daily updates, host AMAs every Thursday 2PM EST."
- Pinned: Links to GitHub, docs, tutorials.
- First post: Share hackathon story and value prop.

## Engagement Plan

- Daily: Quick updates (e.g., "Outreached to 5 projects today!")
- Weekly: AMA with founders, answer dev questions.
- Monthly: Community challenge (best integration idea wins shoutout).

Launch now, invite from outreach targets.
