### Path convention

Routes are documented as `/v1/...` (not `/api/v1/...`) because `apps/api/src/index.ts:30` mounts `apiRoutes` at `app.use("/v1", apiRoutes)`. The OpenAPI paths therefore match what the server actually serves.
