## Summary of Changes

Added `IdlEvents` import from `@coral-xyz/anchor` to `packages/sdk/src/types.ts`.
Exported all 19 event type aliases as PascalCase + "Event" suffix.

Key detail: `IdlEvents<Tributary>` keys are **camelCase** (matching the
IDL type-definition names generated by Anchor), not PascalCase. Using
PascalCase keys causes TS2339 errors on events like `emergencyPauseChanged`
and `referralRewardDistributedRecord`. All 19 aliases use camelCase index
access: `IdlEvents<Tributary>["paymentRecord"]`, etc.

Exports flow through `index.ts` via existing `export * from "./types"`.

Verification: typecheck, build, lint, 13 tests all pass.
