# Tributary - Recurring Payments on Solana

Hey everyone! :wave: I'm the dev behind **Tributary**, and I'm excited to share what we've built – a protocol that finally brings smooth, automated recurring payments to Solana. :rocket:

Tributary lets users sign once to set up subscriptions or donations without locking funds (non-custodial magic via token delegation). No more manual approvals killing UX – payments just flow automatically! :money_with_wings:

As an example, check out **<https://contribute.so>** – it's integrated Tributary to let creators accept monthly donations in USDC/SOL. Currently supports Github and Twitter. Users just connect their wallet, delegate once, and support flows forever. Super simple for creators to monetize, and backers love the control.

If you're building on Solana and want to add subscriptions to your app, Tributary's SDK makes it a breeze. Let's chat integrations!
