## Usage

/produce-tweets

## Objective

Generate 50 high-engagement tweets optimized for Twitter's algorithm based on context, designed for 1-2x daily automated posting over 25-50 days.

Store all the tweets in TWEETS.md - append the file if necessary.

## Phase 1: Project Analysis & Strategy

### Step 1: Extract Core Information

Read and analyze the context file to identify:

- **Core value proposition**: What problem does this solve?
- **Target audience**: Who benefits from this project?
- **Key features**: What are the 3-5 most compelling aspects?
- **Unique differentiators**: What sets this apart?
- **Use cases**: Real-world applications
- **Technical highlights**: Any impressive tech/innovations
- **Community elements**: Social proof, testimonials, milestones

### Step 2: Twitter Algorithm Optimization Strategy

Apply these proven algorithm triggers:

#### Engagement Signals (Highest Priority)

- **Reply bait**: End with questions that prompt responses
- **Controversy/hot takes**: Mild disagreement with common beliefs (when authentic)
- **Pattern interrupts**: Unexpected takes or counterintuitive insights
- **Relatable pain points**: Problems your audience experiences daily
- Feel free to use the "Solana slang"

#### Content Formatting

- **Hook-first structure**: First 1-2 lines must stop scrolling
- **Line breaks**: Use 1-2 line paragraphs for readability
- **Visual hierarchy**: Strategic use of:
  - Bullet points (•)
  - Numbered lists
  - Emojis (2-3 max, 1 min, strategically placed)
  - ALL CAPS for 1-2 words max (sparingly)

#### Timing & Psychology

- **Novelty**: "New way to...", "Just discovered...", "Here's what nobody tells you..."
- **Curiosity gaps**: Tease information without revealing everything
- **Social proof**: Mention results, numbers, testimonials
- **FOMO**: Limited perspective, exclusive insights, early access themes

#### Technical Optimization

- **Length**: Optimal 150-280 characters (forces engagement to see full thought)
- **Hashtags**: 1-2 max, highly relevant only (algorithm deprioritizes heavy hashtag use)
- **@mentions**: Only when genuinely relevant (1 per tweet max)
- **Thread potential**: Some tweets should invite "reply with thread" responses

## Phase 2: Tweet Generation Framework

### Content Pillars (Distribute across 50 tweets)

1. **Educational Value** (30% - 15 tweets)

   - How-to insights
   - Problem-solving approaches
   - Industry knowledge
   - Technical explanations made simple

2. **Social Proof & Results** (20% - 10 tweets)

   - Milestones achieved
   - User testimonials
   - Before/after scenarios
   - Success metrics

3. **Thought Leadership** (20% - 10 tweets)

   - Industry observations
   - Hot takes (when appropriate)
   - Predictions and trends
   - Contrarian viewpoints

4. **Behind-the-Scenes** (15% - 7-8 tweets)

   - Development journey
   - Lessons learned
   - Challenges overcome
   - Team insights

5. **Community & Engagement** (15% - 7-8 tweets)
   - Questions to audience
   - Polls and opinions
   - User-generated content
   - Community highlights

### Tweet Formulas (Mix These)

**Formula 1: Problem-Agitate-Solution**

```
[Relatable problem]

[Why it's frustrating]

[Your project solves it by...]

[Specific benefit]
```

**Formula 2: Curiosity Hook**

```
I just realized something about [topic]...

[Unexpected insight]

[How it relates to project]

What do you think?
```

**Formula 3: Listicle Tease**

```
[X] things I wish I knew about [topic]:

1. [First point]
2. [Second point]
3. [Leads to your project]

Which surprised you most?
```

**Formula 4: Controversial Take**

```
Unpopular opinion:

[Mildly controversial statement]

[Why you believe it]

[How project embodies this philosophy]

Agree or disagree?
```

**Formula 5: Story Arc**

```
[Time period] ago, I [had problem]

Today, [situation improved]

The difference? [Your project/approach]

[Specific transformation]
```

**Formula 6: Value Bomb**

```
[Bold claim or number]

Here's exactly how:

→ [Point 1]
→ [Point 2]
→ [Point 3]

[Call to learn more]
```

## Phase 3: Generation Requirements

### For Each Tweet, Include

1. **Tweet text** (formatted for copy-paste)
2. **Best posting time recommendation** (e.g., "Weekday 9-11am or 7-9pm")
3. **Expected engagement type** (replies, retweets, likes)
4. **Content pillar category**
5. **Follow-up action** (optional: what to do if it performs well)

### Quality Checklist

Before finalizing each tweet, verify:

- [ ] Hook in first 10 words stops scrolling
- [ ] Contains specific value/insight, not generic
- [ ] Encourages engagement (question, disagreement, curiosity)
- [ ] Formatted for mobile readability (line breaks)
- [ ] Authentic voice (not overly salesy)
- [ ] Clear connection to project without being pushy
- [ ] Under 280 characters
- [ ] No more than 2 hashtags
- [ ] No link in tweet (Twitter deprioritizes links; use bio or first reply)

### Variety Matrix

Ensure diversity across 50 tweets:

- **Tone**: Educational, humorous, inspiring, challenging, personal (mix)
- **Length**: Short (1-2 lines), medium (4-5 lines), long-form (8-10 lines)
- **Format**: Plain text, bullet points, numbered lists, question-based
- **CTA intensity**: Soft (implicit), medium (suggestive), direct (explicit ask)

## Phase 4: Output Format

```markdown
## [Tweet text exactly as it should be posted]
```

## Phase 5: Advanced Optimization

### A/B Testing Suggestions

For every 10 tweets, note 2-3 alternative variations you could test:

- Different hooks for same content
- Question vs. statement format
- Different emoji placement

### Engagement Strategy

- **Tweets 1-10**: Focus on value and education (build trust)
- **Tweets 11-25**: Mix value with social proof (build credibility)
- **Tweets 26-40**: Increase thought leadership and hot takes (build authority)
- **Tweets 41-50**: Strong CTAs and community focus (build action)

### Red Flags to Avoid

- ❌ Starting with "I'm excited to announce..."
- ❌ Using corporate buzzwords
- ❌ More than 3 hashtags
- ❌ External links in tweet body
- ❌ "Check out", "Learn more", "Click here"
- ❌ All text same tone/length (algorithm detects automation)
- ❌ Posting same time every day (vary by 30-90 minutes)
